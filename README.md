Mi App VeterinariaL
Este es el código de mi aplicación móvil para gestionar mascota.
La hice para una tarea de SENATI y me gusta mucho cómo quedó. 

¿Qué hace?
Listar: Muestra todas las mascotas que tengo registradas.

Registrar: Agrega una nueva mascota a la base de datos.

Buscar: Encuentra una mascota por su ID.

Actualizar: Edita los datos de una mascota que ya existe.

Eliminar: Borra una mascota.

¿Cómo funciona?
La app está hecha en Android Studio usando Java. Para conectarse a mi base de datos, usa la librería Volley para las peticiones a mi API REST.


Estructura del proyecto
MainActivity.java: Es la pantalla principal con los botones.

Registrar.java: La pantalla para agregar mascotas.

Buscar.java: Para buscar, actualizar y eliminar.

Listar.java: Muestra la lista de mascotas.
